# Showcase + Shopee

- Edit produk: `scripts/seed.mjs` (array `products`)
- Edit teks/judul/link toko: `app/page.js` (objek `SITE`)
- Taruh foto di `public/images/`, lalu isi `image: "/images/namafile.jpg"`
- Jalankan lokal: `npm install && npm run dev`
- Deploy: push ke GitHub, import repo di vercel.com. Database SQLite dibuat otomatis saat build.
